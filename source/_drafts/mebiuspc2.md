## 没有浏览器怎么网上冲浪

没有浏览器当然网上冲浪不了！所以来选择你的浏览器吧！

### 1.Microsoft Edge 是前女友和豪门千金的女儿

至于哪个母亲？那当然是我们的巨头企业谷歌家的千金 Google Chrome了。现在的Edge虽然名头上还是微软的浏览器，但是已经使用着谷歌的Chroium的内核了嚯哈哈哈哈哈哈哈哈哈！

不过，即使是这样出身高贵的Edge，来到神秘的东方大陆后，也得入乡随俗，已经☆完☆全☆恶☆堕☆力！（悲）

可以在右上角的齿轮标志处，关闭内容，获得暂时清爽的搜索环境！

但是Edge恶堕的过于严重，设置里充满了大量完全用不上且看着就烦的无意义选项。（应该有图）

没关系，反正Edge只是一个跳板，让我们去寻找其他的浏览器吧！

### 1.5.但是首先需要打开宝箱的钥匙7-ZIP

互联网上的很多宝藏，都会以压缩包宝箱的形式被我们发现。

虽然有很多解压软件，但我还是首推7-ZIP，其他大佬可能会有别的推荐，但我确实只喜欢用这个所以也只推荐这个。

**官网在这里：https://7-zip.org/**

现行的大部分Win10和Win11系统都是64位的，所以选择x64版本download下载安装即可。

7ZIP的优势在于，占用小，功能强。使用也很方便，右键直接选择即可（如果是win11系统可能需要显示更多选项）

**如果要压缩文件传给他人，请压缩为ZIP格式方便解压，如果是自己备份建议使用7z格式，压缩效果更好！**

* 如果你的系统是32位的，那它显然不是新电脑所以不适用于本开荒心得（因为懒得写所以切割了！）

* （如何查询系统成分请自行百度）

### 1.5.1 可恶的Win11快让我右键显示所有选项！

1.用鼠标右键点击“开始”按钮（或者按Win+X键），选择点击 “Windows 终端（管理员）”

2.复制【reg.exe add “HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32” /f /ve】粘贴回车，然后重启系统（Explorer.exe）即可。

3.虽然我觉得不大可能但是以防万一，如果想恢复Windows11右键菜单

复制【reg.exe delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /va /f】粘贴回车，然后重启系统（Explorer.exe）即可。

4.【最新的版本答案】时隔多年后我发现了一款软件可以解决这个问题，那就是FluentContextMenu-右键菜单增强 https://www.bilibili.com/video/BV1UkQyYCERL/



### 2.RunningCheese Edge是奔跑中的工具人

既然Edge只是恶堕，那么有没有办法可以拯救她呢？

当然有！总之省略了一万字以后，博主奔跑中的奶酪发布了一系列调教好的浏览器。包括但不限于RunningCheese Edge，Chrome和Firefox。他们兄弟三人是已经被调教的服服帖帖的好用的工具人。浏览器拓展和脚本都已经部署到位，只要下载就能直接爽用！

不过别人调教的自然也有不方便之处，适合大佬们使用习惯的浏览器往往装载了过于繁杂的功能，其实并不一定适合所有人。

### 2.5.总之有了运行库才能让你干什么都不报错

在 Windows 环境下，很多软件（特别是游戏、或者某些独立者开发的软件）都需要依赖一些运行库才能正常使用，而这些库并没有集成在 Windows 里的，需要我们自行下载安装。

是时候介绍一下All In One Runtimes了，一键安装运行库，总之安装链接我也会想办法准备好的！

* 最常见的有 DirectX**、**VC++ 运行库和 .Net Framework框架等，大概会有这些名字：

  Microsoft .Net Framework

  Direct X

  JRE (Java Runtime Environment) Java 运行环境

  Visual C++ Runtime

  Adobe Flash Player

  总之还有很多。

**软件列表会出现很多 C++ 开头的运行库，千万别删。**

**也不要有「这么多没有用，留一个就行了之类的想法」，因为真的有用！**
