# 一.前情提要

近日因为在打一些字的时候担心被输入法监控记录，又在购物软件常被大数据困扰，只搜得到性价比产品，找不到较为美观的，没法送对象，大为光火。遂开始研究如何调教输入法。主要考虑几点需求如下：

> * 自定义界面、字体 （纯白输入法晚上冲击太大，字体太丑太小影响个人使用体验）

# 二.先说结论

**结论是在Windows上使用微软拼音，Android上使用讯飞输入法小米定制版+Swiftkey+创建快捷方式（可用的屏幕键盘）**

微软拼音为Windows自带，现在感觉功能也很全面，只有在输入繁体大五码的时候可能需要搜狗输入法，随便找个绿色老版本即可。

日常使用讯飞，有需求时使用快捷方式跳转切换输入法为Swiftkey。

## 1.讯飞输入法小米定制版

先谈谈为什么用这个。

> * 讯飞的语音输入应该是输入法界中领先的。
>
> * 可以在拼音输入的同时使用手写功能。
> * 小米定制版相较于其他版本稍微清爽一点。
> * 颜文字、皮肤（包括工具栏）、输入感觉（声音、振动）功能的自定义功能较为全面。
> * 在使用小米的隐私输入功能的同时，仍然可以使用皮肤（偶尔会抽风），颜文字，自定义输入感觉（声音、振动）功能。这点完全击败了搜狗的小米定制版本。搜狗的小米定制版一旦使用基础输入模式，无法修改任何操作体验，只能忍受白色键盘和巨大的打字音效振动。

我从以前使用家里人淘汰的旧OPPO的时候，就已经开始使用讯飞小米定制了。虽然这两年新版本新小米手机的定制其他的冗余功能也不少，但是确实一直相对好用。使用前需要去设置里把那些节日祝福什么的全关掉，即可拥有较为舒服的输入体验。

**但是，在使用隐私输入模式的时候，包括小米通知栏自带的屏幕翻译等情况会无法使用，并且偶尔会抽风。（如皮肤消失术）**

所以我们需要一个另外的隐私输入法，我选择了Swiftkey。

## 2.Swiftkey

Swiftkey，微软在Android做的输入法，iOS有没有不知道。ios倒是一直用的系统输入法。

Swiftkey同样拥有充分的自定义功能，词库也还可以——毕竟那么多人在用微软拼音。但是语音输入和一些细节方面肯定是不如讯飞的。起码在中文输入法领域而言。

Swiftkey有个不得不提的优点，长按空格键可以选择光标位置。

## 3.创建快捷方式

为什么需要这个软件？因为在Android上没有快捷的切换输入法方式。很久以前小米的通知栏有一项是快捷切换输入法，现在没了。

> 需要记得先把相关的权限都打开。
>
> > 点击右上角三个点/也搜索活动列表/也搜索未导出的活动/也显示系统应用
> >
> > > 搜索 设置/可用的屏幕键盘，添加到桌面即可。

顺带一提，这个软件在国产Android上还有一个可以打开系统文件管理器的方式。是Android的那个，不是国内系统的文件管理。

# 三、笔者失败的探索：Rime

Rime是一款跨很多个系统的输入法引擎，总之很牛逼。听说很多双拼五笔爱好者会去研究这个输入法，本博客的另一位编写者AF在Linux上也使用的这个。

笔者尝试使用了一下这个输入法，最后大失败，原因如下：

> * 功能太少。语音输入，颜文字，在拼音键盘上进行手写输入全部没有。不过这也是难免的。
> * 自定义似乎很全面，但是有一定门槛。
> * 不好用，纯粹的不舒服，打字的时候手感怪怪的，虽然似乎因人而异，但还是很难受。
> * 事到如今，较为繁琐的安装方式好像也还可以接受了。

**以上这些缺点都是笔者的一家之言，我个人是相信有很多厉害的大佬可以把Rime调教得随他心意的，但是笔者技术力有限。**

至于多平台同步词库，我在电脑上也没有更换讯飞输入法的打算。虽然它确实好用，但是一来PC端的输入不需要太花里胡哨，二则是我倒没兴趣让人更大范围的窃取隐私。 因此也只好作罢了。
